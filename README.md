# CI/CD DevOps Pipeline

This project demonstrates a complete CI/CD pipeline for a Java-based application using modern DevOps tools and practices. It automates the entire software delivery lifecycle including source code management, application build, code quality analysis, containerization, image storage and deployment to a Kubernetes cluster. The pipeline integrates Jenkins, Maven, SonarQube, Docker, Nexus Repository and Kubernetes to provide a reliable, automated and scalable deployment workflow.

## Key Features

- Automated CI/CD pipeline using Jenkins
- Application build and testing with Maven
- Code quality analysis using SonarQube
- Docker image creation and management
- Docker image storage in Nexus Repository
- Kubernetes-based application deployment
- Automated deployment verification
- End-to-end DevOps workflow automation

## Purpose

This project demonstrates the implementation of a complete CI/CD pipeline using DevOps tools. It serves as a hands-on learning project for Jenkins, Docker, Maven, SonarQube, Nexus Repository, Kubernetes and continuous integration and deployment practices.
